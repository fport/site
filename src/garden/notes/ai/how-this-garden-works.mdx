Everything here is a plain `.mdx` file in the repo. No database, no editor —
notes are written in the editor, committed, and deployed.

## Adding a note

1. Create `src/garden/notes/ai/my-note.mdx` and write it.
2. Register it in `src/garden/ai.ts` (title, kind, tags, cluster, links).
3. Place it: open the canvas with `?edit=1`, drag and resize the card, then
   hit **Copy layout** and paste the result over `src/garden/ai.layout.ts`.

That last step is the whole trick — the layout you arrange by hand comes back
out as code, so the canvas stays completely static.

<Callout type="idea" title="Why static">
  A note is worth as much as it is easy to write. Files in git mean diffs,
  search, and no second system to keep alive.
</Callout>
