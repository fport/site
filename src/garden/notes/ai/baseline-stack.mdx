<Callout type="gotcha" title="Full reset">
  Wiping the collection and rewriting it on every index build is harmless in a
  baseline and wrong in production: one changed document re-embeds the whole
  corpus. Incremental upsert keyed on a document hash is the first fix.
</Callout>
