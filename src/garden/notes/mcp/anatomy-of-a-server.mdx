A server is smaller than it sounds. It declares what it can do, then answers
two kinds of call for each primitive: *list them* and *do one*.

<Callout type="note" title="Stateless by default">
  Since the stateless core landed, a request no longer assumes it lands on the
  instance that handled the last one. Keep per-request state out of process
  memory, or put it behind something shared.
</Callout>

<Sticky accent="violet">
  The hardest part of writing a server is not the protocol — the SDKs handle
  that. It is deciding what to expose and what to keep out of reach.
</Sticky>
