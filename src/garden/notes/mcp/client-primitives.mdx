The protocol was originally two-way: a server could call *back* into the client
to borrow the model, ask the user something, or read the workspace roots.

All of these needed a held-open bidirectional stream, which is exactly what the
stateless core removed.

## What replaced elicitation

**Multi Round-Trip Requests.** Instead of pushing a question down an open
stream, the server returns `resultType: "input_required"` along with what it
needs. The client collects the answers and **retries the original call** with
them attached.
