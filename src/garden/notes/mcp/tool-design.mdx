## The failure modes

- **Tool soup.** Forty tools with terse names. The model picks wrong, and no
  amount of prompt engineering above it fixes a bad menu.
- **Swallowed errors.** A tool that returns an empty result on failure teaches
  the model that the answer is "nothing".
- **Unpaginated returns.** One tool dumping a full JSON document is the most
  common cause of a blown context window.

<Callout type="idea" title="Write the description for a new colleague">

</Callout>
