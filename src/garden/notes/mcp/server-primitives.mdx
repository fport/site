## The wire methods

Discovery and use are separate calls, and each has a list side and an act side:
`tools/list` then `tools/call`, `resources/list` then `resources/read`,
`prompts/list` then `prompts/get`.

<Callout type="note" title="List results are cacheable">
  Since the 2026-07-28 spec, list responses carry a `ttlMs` and a cache scope,
  so a client does not re-enumerate a server's catalogue on every turn.
</Callout>

<Sticky accent="lime">
  If you are unsure whether something is a tool or a resource, ask: should the
  model be allowed to trigger it on its own? Yes → tool. No → resource.
</Sticky>
