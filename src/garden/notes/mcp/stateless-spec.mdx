## Why statelessness was the blocker

With a handshake and a session id, every request had to land on the instance
that started the conversation. That means sticky sessions, no plain
round-robin, and a lost stream losing the session.

<Callout type="idea" title="Header routing is the operational win">
  Because `Mcp-Method` and `Mcp-Name` ride in headers, a gateway, rate limiter
  or WAF can route and meter per tool **without parsing the JSON body**. That is
  the difference between "we host it" and "we can operate it".
</Callout>
